# AI Concept Explainer

AI Concept Explainer is an educational chat application built with Chainlit and LangChain that leverages Google's Gemini AI to explain concepts tailored to your specific learning level and preferred language.

## Features
* **Adaptive Learning Levels**: Choose between Beginner, Intermediate, or Advanced explanations[cite: 1].
* **Multi-Language Support**: Get answers in English, Hinglish, or Hindi[cite: 1].
* **Structured Responses**: Every explanation includes a Meaning, How it works, Example, and Key takeaway[cite: 1].

## Prerequisites
* Python 3.11 or 3.12[cite: 1]
* A valid Google Gemini API key[cite: 1]
